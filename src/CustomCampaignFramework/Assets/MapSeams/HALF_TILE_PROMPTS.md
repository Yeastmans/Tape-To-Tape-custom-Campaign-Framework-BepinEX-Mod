# A/B half-tile transitions

Built-in image generation was used for all three A-to-ending patches. Existing act-N-transition.png patches connect B to A. A to B and B to ending use original continuous artwork. Use Start + A + (B + A)* + optional B + Ending; boss remains in the final ending section. Each A/B piece has width W/4. Total width is (parts + 2) * W/4; boss offset from its original anchor is (parts - 2) * W/4 converted to world units. One or more middle parts are supported. Nearest half count minimizes horizontal spacing adjustment.

The generated seam patches preserve the visual composition, but generated edges are not claimed pixel-identical. Their outer 2% is feathered for raster alignment. Gameplay validation remains outstanding.
