========================================
     VALID VALUES — QUICK REFERENCE
========================================
Reference for the Campaign Creator.
Each section lists every accepted value.


========================================
  Section 1 — BODY / JERSEY
========================================
What the player's torso looks like.
Pick a skin OR write an RGB color (e.g. 0,51,160) to use the
default jersey with that color.

standard            Default jersey — set color with Jersey Primary / Jersey Color
tycoons             Business suit — has its own look, ignores color
princess            Knight armor — has its own look, ignores color
golfers             Polo shirt — has its own look, ignores color
prisoners           Jumpsuit — has its own look, ignores color
mountaineers        Mountain gear — has its own look, ignores color
hockey fc           Soccer jersey — has its own look, ignores color
figure skaters      Figure skater outfit — has its own look, ignores color
referee             Referee stripes — has its own look, ignores color
random body         Picks a random skin each game
R,G,B               Write a color directly (e.g. Body = 0,51,160)
                    This auto-uses the default jersey with that color


========================================
  Section 2 — HELMET
========================================
team colors         Default helmet — set color with Helmet Color fields
cage                Wire face cage — has its own look, ignores color
random helmet       Picks a random skin each game
R,G,B               Write a color directly (e.g. Helmet = 200,0,0)


========================================
  Section 3 — STICK
========================================
black               Black stick
gold                Gold stick
red                 Red stick
purple              Purple stick
teal                Blue-green stick
red gold            Red and gold stick
sword               Sword instead of stick
golf                Golf club instead of stick
team stick          Default stick — set color with Stick Color
random stick        Picks a random skin each game
R,G,B               Write a color directly (e.g. Stick = 50,50,50)


========================================
  Section 4 — SKATES
========================================
Has 3 color channels: Skates Color (body), Blade Color, Laces Color.

standard            Default skates — set 3 colors below
random skates       Picks random colors for all 3 channels
R,G,B               Write a color directly (e.g. Skates = 0,0,0)


========================================
  Section 5 — GLOVES / PANTS / BICEP
========================================
These always use the default model. Just set the color.
Write RGB directly (e.g. Gloves = 0,51,160) or use the
color fields (Gloves Color, Pants Color, Bicep Color).

No skin options — only color matters.

========================================
  Section 8 — COLORS (RGB)
========================================
Format: R,G,B (three numbers 0-255)

255,0,0             Red
0,255,0             Green
0,0,255             Blue
255,255,0           Yellow
255,255,255         White
0,0,0               Black
128,128,128         Grey
255,165,0           Orange
128,0,128           Purple
0,255,255           Cyan
255,192,203         Pink

Special values:
random              Fully random color
random(min,max)     Random per channel
(blank)             Uses team/default color
