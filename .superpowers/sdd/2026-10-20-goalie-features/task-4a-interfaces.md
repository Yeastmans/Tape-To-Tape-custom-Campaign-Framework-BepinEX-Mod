# Task 4a interface contract (before implementation)

- `GoalieContractPolicy.Sign(int)` requires a positive duration and returns zero progress. `CompleteMatch(state,key,participants,prevented)` accepts only an exact nonempty `ArmedAttemptToken`, unless the key is already in `ProcessedAttemptTokens` (detached no-op). It consumes the accepted token in the same returned state as counters and reconciliation. Unknown participants are rejected. Task 4b owns durable arming and immutable node/owner context; Task 4c alone calls completion after proven live participation and successful post-boss update. Policy does not infer native attempt authority.
- `ReconcileDeparture(state,prevented)` clones all state, preserves recruitment ledger, removes unprotected expired reserve first, promotes a valid reserve for unprotected expired active, otherwise retains that active with AwaitingReplacement. Protection retains counters and occupants. No native collections are involved.
- Frozen authored duration is prepared with existing `PlayerContractOptions.Duration`; recruitment offer owns a detached signed snapshot and confirmation passes it through Task 3 `signedContract`. Fresh-run hook signs from selected squad goalie authoring once. Load never reads authoring.
- Reusable native decision: `GoalieContractRuntime.TryDepartureProtection(CampaignState,out bool)` returns false on unavailable/mismatched state or predicate error; output is usable only on true. It uses the native typed `TeamData.HaveRelicCached<Rogue.Handcuffs>()` and the same extracted `CustomRewardContractRetention.Prevents(TeamData)` consumed by the existing native-manager prefix. Task 4c must capture this in its scoped departure boundary, explicitly handling actual custom prefix skip ordering; this unit does not observe native completion.
- Deferred reserve signing previews and confirms the current known protection decision. A changed decision invalidates confirmation and refreshes the pre-confirmation result; unknown decision prevents reserve signing. Explicit active replacement remains user-directed replacement. Task 3 SaveChange remains sole save coordinator.

Ruling: Preserve shared/skater parsing exactly. Default four is written by actual editor enable/save; enabled absent or invalid hand-edited duration is permanent fallback with warning, never zero. Cost if wrong: a malformed manual config gets permanent fallback instead of the author's intended temporary duration. Controller confirmed this interpretation.

## Implemented rulings and downstream handoff

- Ruling: Completion requires the exact armed key; a known processed key returns a detached no-op before checking current authority or participants. Cost if wrong:4b/4c integration without durable arming rejects a legitimate completion. That failure is intentional; coordinate keys or completion-generated keys are not a fallback.
- Ruling: Typed native/custom protection is tri-state at the adapter boundary (known protected, known unprotected, unknown). Unknown blocks deferred reserve signing. Cost if wrong: a failing dependency can temporarily prevent hiring into Reserve; it cannot unexpectedly remove the expired active. Native default-mode prefix short-circuit was preserved exactly during extraction.
- Ruling: A deferred reserve action previews both resulting slots and re-evaluates protection on the second activation; changed protection updates the preview and requires another activation. TryRecruit accepts nullable `expectedDeparturePrevention` as its last parameter and rejects a mismatch before publication. Cost if wrong: a changing relic/ownership result can require an extra confirmation, avoiding a silently different roster outcome.
- No state schema additions in4a. CompleteMatch clears only ArmedAttemptToken and appends its accepted key to ProcessedAttemptTokens;4b will extend context and must clear/consume any added context consistently. RecruitmentVisit is cloned untouched by all pure policy transitions.
- `GoalieContractRuntime.Sign(CampaignDocument,string)` returns a detached zero-played contract or null, with a warning for enabled malformed values. `OfferText(GoalieContractState)` formats the actual signed snapshot. Offer.Contract clones on both read and write.
-4c must reuse `CustomRewardContractRetention.Prevents(TeamData)` while capturing the actual manager prefix decision; the4a adapter has no callback capture facility and does not certify manager ordering. `TryDepartureProtection` returns unknown on any scope/predicate exception. The wrapper only supplies a current decision;4c owns the original live attempt and successful post-boss boundary.
