# Tape to Tape — Custom Campaign Framework

Create fully custom campaigns for **Tape to Tape** using the included **T2T Campaign Creator** GUI. No config files or coding required.

---

## Installation

1. Download `T2T_Custom_Campaign_Framework_Setup.exe` from the [latest release](https://github.com/Yeastmans/Tape-To-Tape-custom-Campaign-Framework-BepinEX-Mod/releases/latest)
2. Run the installer — it auto-detects your Tape to Tape Steam install
3. Launch the game once to finish setup
4. Open **T2T Campaign Creator** from your desktop shortcut

---

## Using the Campaign Creator

### Home
Switch your active campaign, browse all your content, and check for updates. The mod loads whichever campaign is set as active when you start a run.

### Campaign Settings
Set the campaign name, act sequence (how many maps and what difficulty), and options like replacing Spartan challenge games with full matches.

### Teams
Add and manage the opponent teams your campaign. Drag to reorder them. Each team has:
- Name, city, abbreviation, logo
- Home and away jersey colors + all equipment colors
- Starting relics and talent pool options

### Players
Edit each player on a team — stats, face, body/stick skins, talents, ability, and individual color overrides. The goalie has its own editor for goalie-specific stats and equipment skins. A roster preview shows all players with their overalls, talents, and abilities.

### Player Teams
Create and edit the squads players can choose at the start of a run. Set the squad face, starting relics, and the draft pool of free agents available mid-run.

### Community
Browse and download campaigns shared by other players, or share your own.
